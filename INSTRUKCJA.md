# Jak zainstalować apkę na telefonie — instrukcja krok po kroku

## Krok 1 — Wejdź na GitHub i utwórz nowe repozytorium

1. Wejdź na https://github.com
2. Zaloguj się na swoje konto
3. Kliknij zielony przycisk **"New"** (lewy górny róg)
4. W polu "Repository name" wpisz: **kalistenia**
5. Upewnij się że zaznaczone jest **Public**
6. NIE zaznaczaj "Add a README file"
7. Kliknij **"Create repository"**

---

## Krok 2 — Wgraj pliki na GitHub

1. Na stronie nowego repozytorium kliknij **"uploading an existing file"**
2. Otwórz folder **kalistenia_app** z Pulpitu
3. Zaznacz WSZYSTKIE pliki i foldery (Ctrl+A) i przeciągnij do przeglądarki
   - WAŻNE: foldery .github i lib muszą być wgrane razem z zawartością
   - Jeśli GitHub nie przyjmuje folderów — patrz poniżej (metoda alternatywna)
4. Kliknij **"Commit changes"**

### Metoda alternatywna (przez GitHub Desktop — polecam):
1. Pobierz GitHub Desktop: https://desktop.github.com
2. Zaloguj się swoim kontem GitHub
3. Kliknij "File" → "Add local repository" → wybierz folder kalistenia_app z Pulpitu
4. Jeśli zapyta o "init" — kliknij tak
5. Kliknij "Publish repository" (góra ekranu)
6. Upewnij się że "Keep this code private" jest ODZNACZONE
7. Kliknij "Publish Repository"

---

## Krok 3 — Poczekaj na zbudowanie APK (ok. 5-8 minut)

1. Wejdź na stronę swojego repozytorium na GitHub
2. Kliknij zakładkę **"Actions"** (górne menu)
3. Zobaczysz "Build APK" — czeka lub jest w trakcie
4. Zielona ikona ✓ = gotowe!
5. Kliknij w "Build APK" → kliknij **"Kalistenia-APK"** pod "Artifacts"
6. Pobierz plik ZIP → rozpakuj → znajdziesz **app-release.apk**

---

## Krok 4 — Zainstaluj APK na telefonie

1. Prześlij plik **app-release.apk** na telefon (przez kabel USB, email, lub Google Drive)
2. Na telefonie wejdź w **Ustawienia → Bezpieczeństwo**
3. Włącz **"Nieznane źródła"** lub **"Instalowanie nieznanych aplikacji"**
4. Otwórz plik APK na telefonie → kliknij "Zainstaluj"
5. Gotowe! Szukaj aplikacji "Kalistenia" 💪

---

## Co zawiera aplikacja

- **6-tygodniowy program kalisteniki** (bez sprzętu, lub z drążkiem)
- **Tygodniowy jadłospis** z przepisami (~2000 kcal, ~150g białka dziennie)
- **Timer treningu** z odliczaniem przerw między seriami
- **Tracker wagi** z wykresem postępów
- **Historia treningów**

Program jest dopasowany do osoby zaczynającej od zera, ćwiczącej w domu.
Tydzień 1-2: 4 treningi/tydzień | Tydzień 3-6: 5 treningów/tydzień
